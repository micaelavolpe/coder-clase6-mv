Hablemos de tu proyecto

Sobre este proyecto

Este portafolio forma parte de mi aprendizaje en desarrollo web. En él aplico los conocimientos adquiridos sobre HTML5, CSS3, diseño responsive y organización de páginas web.

Objetivos

Mi objetivo es construir sitios web claros, accesibles y adaptables a diferentes dispositivos, aplicando buenas prácticas de estructura y diseño.

Herramientas adquiridas

Durante el desarrollo del proyecto trabajé con HTML, CSS, Bootstrap, Git y GitHub, incorporando herramientas para organizar el código y mantener un historial de cambios.
