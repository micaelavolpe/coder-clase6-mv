# Portafolio - Primer proyecto Web

Proyecto desarrollado para el curso de **Desarrollo Web** en Coderhouse.

## 🚀 Sitio desplegado
Podés ver la versión en vivo del sitio acá:
👉 [Ver Sitio en GitHub Pages](https://micaelavolpe.github.io/coder-clase6-mv/index.html)

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- Bootstrap 5

## 📁 Estructura del proyecto
- index.html: página principal.
- pages/: páginas internas, como Sobre mí, Proyectos, FAQ y Contacto.
- css/: hojas de estilo compiladas.
- scss/: archivos fuente SCSS.
- img/: imágenes utilizadas en el sitio.
